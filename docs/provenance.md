# Artwork, licensing, and provenance

## Included work

The [MIT license](../LICENSE) covers the code, documentation, and original artwork included in this repository, including the editable projects and rendered showcase images. Commercial use, modification, and redistribution are permitted under those terms.

The included showcases were authored through repository drawing code and PixelHand's tools. Their source projects and authoring scripts are retained so changes can be inspected and the previews rebuilt. Contribution artwork should be original and accompanied by editable source.

PixelHand does not impose licensing terms on new artwork you create with the engine. Reused repository artwork remains subject to its MIT notice; separately imported material keeps its own terms.

## Imported assets

`import_png` requires a declared origin. Licensed imports also require a license and source URL. Imported cels carry provenance records and are flagged for review; export requires explicit permission to include imported material.

```json
{
  "origin": "licensed",
  "licence": "CC-BY-4.0",
  "source_url": "https://example.com/your-licensed-asset",
  "declared_by": "artist-name"
}
```

This is metadata supplied by the caller, not a verification of ownership or permission. Check the actual source terms before importing or distributing outside material. The repository license does not replace those terms.

## Design references

Describe art direction through visual properties: projection, proportions, palette, lighting, edges, materials, and motion. Keep the included examples and contributions original rather than copying existing characters, environments, or palettes.

The [historical provenance notes](archive/07-provenance.md) document early project decisions. This page defines the current repository policy.
