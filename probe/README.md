# Feasibility experiments

Historical PNG, grid, drawing, and MCP experiments retained as development evidence. Some craft gates in `bench/` reuse the drawing fixtures here.

These files are not public engine entry points and are excluded from the npm archive. Use the [runnable example](../examples/lantern.js), [current guide](../docs/guide.md), or `src/mcp.js` for integrations.

The image-returning MCP spike is `spike-mcp.js`; it uses the adjacent experimental `png.js` helper.
