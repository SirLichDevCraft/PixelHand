# Farmhouse

An original architectural study authored with PixelHand: warm roof and timber ramps, cool foliage, small window highlights, and a readable silhouette.

![Farmhouse rendered by PixelHand](preview.png)

## Source and reproduction

The editable project lives in [art/](art). From the repository root, rebuild it and its preview with:

```sh
node bench/showcase-farmhouse.js
```

The script writes the authored project and `preview.png` in this directory. This is a deterministic authored example rather than an autonomous model evaluation.
